# HU-101 — Cupom de desconto no checkout

**Épico:** Checkout · **PO:** Rafael Tavares · **Sprint:** 42

**Como** cliente
**quero** aplicar um cupom de desconto no checkout
**para** pagar menos nas minhas compras.

## Regras
1. O cliente digita o código do cupom no campo "Cupom" e clica em "Aplicar".
2. Cupons de campanha dão 10% de desconto.
3. Compras grandes ganham frete grátis junto com o cupom.
4. O desconto aparece no resumo do pedido.
5. Cupom inválido mostra uma mensagem de erro.

## Critérios de aceite
- O desconto é aplicado corretamente.
- O sistema deve ser rápido ao aplicar o cupom.
