# Política de Acesso a Dados — Aurora Varejo

Versão 2 · vigente desde 2025-02-01

1. Todo pedido de acesso informa: solicitante, ativo, **finalidade**, prazo e gestor.
2. O dono do dado aprova. Para ativo `restrito`, o encarregado também aprova.
3. Acesso concedido tem prazo máximo de 12 meses e é revisado a cada 6 meses.
4. Quando uma visão sem colunas pessoais atende à finalidade, ela deve ser preferida.
5. O log de acesso aos ativos fica na plataforma de dados e é consultado pela Segurança sob
   demanda; ele não é replicado no catálogo.
