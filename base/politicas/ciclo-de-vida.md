# Política de Ciclo de Vida e Depreciação — Aurora Varejo

Versão 1 · vigente desde 2025-06-01 · dono: Comitê de Governança de Dados

1. Ativos com status `depreciado` não recebem novos consumidores.
2. Consumidores existentes migram para a fonte substituta antes da data de exclusão.
3. A linhagem dos ativos reflete a fonte efetivamente utilizada.
4. Consumidores que dependem de ativo depreciado têm plano de migração registrado.
5. A depreciação de uma fonte gera alerta aos seus consumidores conhecidos.
